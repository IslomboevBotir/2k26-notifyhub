# 🧩 Лабораторная работа №1
## Проект: NotifyHub — сервис уведомлений

### 📘 Описание задания
NotifyHub — консольное приложение, которое моделирует сервис рассылки уведомлений. Похожие сервисы есть во многих продуктах: в банках, интернет-магазинах, университетских порталах.

Система позволяет:
- создавать уведомления разных типов (тревога, напоминание, реклама);
- отправлять их по разным каналам (консоль, файл, Telegram, SMS);
- выбирать язык сообщения (узбекский, русский, английский);
- добавлять к сообщению метку времени, подпись, шифрование;
- хранить историю и статистику отправок.

Реальные сетевые запросы не нужны. Внешние сервисы (Telegram, SMS) **имитируются**: сообщение печатается в консоль с пометкой канала или записывается в файл.

---

### 🧱 Основные требования
1. Язык любой, подход объектно-ориентированный.
2. Обязательно используются **5 паттернов** из таблицы ниже. Бонусные паттерны дают дополнительные баллы.
3. У каждого паттерна должна быть реальная роль в системе. Паттерн «для галочки» не засчитывается.
4. Взаимодействие с пользователем идёт через консольное меню.
5. Возле каждого паттерна в коде стоит комментарий или docstring: какой это паттерн и зачем он здесь.
6. Нужен README с описанием структуры проекта и списком паттернов.

### 🧩 Обязательные паттерны

#### 1. Bridge: тип уведомления × канал отправки
Тип уведомления (**абстракция**) и способ доставки (**реализация**) развиваются независимо. Любое уведомление можно отправить по любому каналу.

```
Notification (абстракция)          Channel (реализация)
├── AlertNotification              ├── ConsoleChannel
├── ReminderNotification   ──▶     ├── FileChannel
└── PromoNotification              ├── TelegramChannel (имитация)
                                   └── SmsChannel (через Adapter)
```
Пример: `AlertNotification(channel=TelegramChannel())`.
Требование: добавление нового канала не должно требовать изменений в классах уведомлений.

#### 2. Abstract Factory: языковые наборы шаблонов
Фабрика создаёт **семейство** согласованных объектов для одного языка: шаблон тревоги, шаблон напоминания, шаблон рекламы.

```
LocaleFactory
├── UzFactory  → UzAlertTemplate, UzReminderTemplate, UzPromoTemplate
├── RuFactory  → RuAlertTemplate, ...
└── EnFactory  → EnAlertTemplate, ...
```
Пример: `RuFactory().create_alert_template().render("Сервер недоступен")` → `⚠️ ВНИМАНИЕ: Сервер недоступен`.
Требование: шаблоны разных языков в одном сообщении смешиваться не должны.

#### 3. Decorator: дополнительная обработка сообщения
Обёртки над сообщением, которые можно накладывать в любом порядке и количестве:
- `TimestampDecorator` добавляет дату и время;
- `SignatureDecorator` добавляет подпись («— Команда NotifyHub»);
- `EncryptDecorator` шифрует текст (шифр Цезаря или Base64);
- `UrgentDecorator` переводит текст в верхний регистр и добавляет 🔴.

Пример: `Signature(Timestamp(Message("Пара перенесена")))`.

#### 4. Adapter: подключение «старого» SMS-шлюза
Дан готовый класс, который **нельзя изменять** (сторонняя библиотека):

```python
class LegacySmsGateway:
    def send_sms(self, phone: str, payload: bytes, priority_code: int) -> int:
        """Возвращает 200 при успехе, 400 при ошибке."""
```

Его интерфейс не совпадает с `Channel.send(recipient, text)`. Нужно написать `SmsChannelAdapter`, который:
- переводит текст в `bytes`;
- преобразует тип уведомления в `priority_code` (Alert → 1, Reminder → 2, Promo → 3);
- превращает код ответа в `True`/`False`.

#### 5. Singleton: история и статистика
`NotificationHistory` — единственный объект на всю программу. Он хранит все отправленные уведомления и умеет:
- показывать историю;
- считать статистику: сколько отправлено по каждому каналу и типу, сколько неудачных отправок.

### ⭐ Бонусные паттерны (+1 балл за каждый, максимум +3)

| Паттерн | Где применить |
|---|---|
| **Composite** | Получатели: `User` и `Group`. Группа может содержать пользователей и другие группы («3 курс» → «Группа 301», «Группа 302»). Отправка группе рекурсивно доходит до каждого |
| **Builder** | `NotificationBuilder().type("alert").locale("ru").channel("sms").to(group).text("...").with_timestamp().build()` |
| **Prototype** | Сохранённые шаблоны рассылок, например «Еженедельное напоминание». Шаблон копируется через `clone()`, в копии меняется только текст или получатель |
| **Facade** | `NotifyHub` с простыми методами `send()`, `show_history()`, `show_stats()`, которые скрывают всю внутреннюю кухню от `main.py` |
| **Factory Method** | `ChannelFactory.create("telegram")` создаёт канал по названию |
